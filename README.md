# Integra Saúde Rio: site (primeira versão)

Protótipo do novo site da clínica Integra Saúde Rio, em Itaguaí (RJ). **Ainda não é o site oficial.**

## Como abrir

Baixe a pasta e abra o `index.html` no navegador. Não há instalação nem compilação. As fontes vêm do Google Fonts, então precisam de internet.

## Estrutura

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Página única |
| `styles.css` | Cores, fontes e layout |
| `script.js` | Menu, letra grande e agendamento |
| `assets/` | Logo, símbolo e imagem |

## Antes de publicar como site oficial

- [ ] Informar nome e CRM do responsável técnico (rodapé)
- [ ] Aprovar com a clínica os textos de "Como agendar", "Dúvidas comuns" e chamadas
- [ ] Ligar o agendamento à agenda real (os horários atuais são de demonstração)
- [ ] Trocar a imagem ilustrativa por fotos da clínica
- [ ] Confirmar a permissão de uso do modelo de layout que serviu de base
- [ ] Remover a linha `<meta name="robots" content="noindex">` do `index.html`
